Alert and Confirm Dialogs

The javaxt.dhtml.utils.alert() and javaxt.dhtml.utils.confirm() methods render modal alert and confirm dialogs using the Window class. Unlike the native confirm(), the confirm dialog doesn't block, so the answer is passed to a callback. The dialogs are styled using the JavaXT themes. Click the buttons below to open the dialogs and use the Light/Dark switch to change the theme.

  //Simple alert. Also accepts an XHR response (e.g. a server error).
    javaxt.dhtml.utils.alert("Something went wrong! Please try again.");

  //Confirm with the default title and OK/Cancel buttons
    javaxt.dhtml.utils.confirm("Are you sure you want to continue?", {
        callback: function(answer){ //true for OK, false for Cancel
            console.log(answer);
        }
    });

  //Confirm with a custom title and buttons
    javaxt.dhtml.utils.confirm({
        title: "Quit Game?",
        text: "Are you sure you want to quit the game?",
        leftButton: { label: "Yes", value: true },
        rightButton: { label: "No", value: false },
        callback: function(answer){
            if (answer===true) console.log("quit game");
            else console.log("continue game");
        }
    });
