Calendar Demo

An interactive month/week/day calendar. This example uses the component's default style, which is defined inline (no stylesheet required). Use the toolbar to navigate and switch views; open the web console to see click events. The colored events carry their own inline style, and the month view is sized so its day cells stay square. Scroll down for the same calendar styled with the JavaXT themes.

Week View

The week view lays out a seven-day timeline. Timed events are positioned by the hour, overlapping events are split into side-by-side columns, and multi-day events span across a bar at the top. This example packs several meetings into each weekday — denser than the month view above — to show the overlap layout. The grid scrolls to reveal the full day.

Day View

The day view is a single-day timeline that shares the week view's rendering. This example shows a busy day whose many overlapping appointments are automatically divided into columns so nothing is hidden. Scroll the grid to see earlier and later hours.

JavaXT Themes

The same calendar styled with the JavaXT themes (themes/light.css and themes/dark.css). The header, grid, hour lines and events are all drawn with CSS classes that follow the active theme. Each theme is shown on its own row in an iframe (so the two stylesheets don't collide) and is auto-sized to fit its square month grid.
