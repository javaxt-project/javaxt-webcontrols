Table Demo

The Table component renders a scrollable table with a fixed header. Scroll through the 200 names below and notice that the header row stays in place. The header and the body are rendered as two separate tables that share the same column widths, so the columns stay aligned as you scroll. Click on a row to select it, then use the up/down arrow keys to move the selection. Open the web console to see events.

Group Headers

The Table doesn't support grouping natively, but you can fake it. Each group header below is a regular row with its first cell stretched across the table (colSpan) and the remaining cells hidden. The row's inline styles and click handler are replaced so that clicking on a header expands or collapses the group instead of selecting the row. Items can still be selected with the mouse or the up/down arrow keys; keyboard navigation skips over the headers.

Section Rows

Section rows are created the same way as the group headers (a full-width row with the other cells hidden) but they don't do anything when clicked. In the example below, messages are organized by date, similar to the inbox in Yahoo Mail. Click on a message to mark it as read. Keyboard navigation skips over the section rows.
